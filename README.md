# Recipe Book

Recipe Book is a React app for discovering and managing recipes. Browse recipes, search by name or cuisine, view recipe details, and add or edit your own recipes.

## Run locally

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build
